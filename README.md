# QA Resume Page

Минималистичная страница резюме QA-инженера, где весь контент хранится в `resume.json`.

## Как редактировать резюме без правки кода

1. Откройте в GitHub файл `resume.json`.
2. Нажмите иконку карандаша (**Edit this file**).
3. Измените нужные поля (имя, опыт, навыки, контакты и т.д.).
4. Нажмите **Commit changes**.

После merge в `main` GitHub Actions автоматически задеплоит новую версию страницы.

## Скачать резюме в PDF

В правом верхнем углу карточки резюме есть кнопка с иконкой скачивания.  
Она генерирует PDF-версию текущей страницы со стилями резюме и скачивает файл на устройство.

## Переключение языка

Рядом с кнопкой PDF доступна кнопка `EN / RU`.  
Она переводит текущую страницу автоматически с русского на английский и обратно без дублирования текста в `resume.json`.

## Визуальные эффекты

- Добавлен `favicon.svg`
- Добавлен полноэкранный фон в стиле liquid glass с мягкими blur-формами
- Для фоновых blur-слоев добавлен легкий параллакс-эффект
- Карточка резюме оформлена как полупрозрачное стекло (glassmorphism)
- Анимации остаются минималистичными и учитывают `prefers-reduced-motion`
- В шапке отображается фото из `profile.photo` в небольшом круге
- По клику на фото открывается увеличенный просмотр по центру экрана
- В верхней панели есть иконка-ссылка на Telegram
- В мобильной версии кнопки действий доступны через кнопку-гамбургер

## SEO и предпросмотр ссылок (Telegram / WhatsApp)

В `index.html` добавлены `description`, Open Graph и Twitter Card мета-теги.  
Если у вас изменится домен или превью-картинка, обновите в `<head>` значения:

- `og:url`
- `og:image`
- `twitter:image`
- `canonical`

## Структура данных

- `meta.pageTitle` — заголовок страницы в браузере
- `profile` — имя, должность, фото (`profile.photo`) и Telegram (`profile.telegram`)
- `summary` — краткое описание
- `contacts[]` — контакты (`label` и опционально `href`)
- `skills[]` — список навыков
- `experience[]` — опыт работы
- `education[]` — образование
- `certifications[]` — сертификаты
